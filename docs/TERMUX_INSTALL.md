# Install AURA on Android using Termux

AURA's Android APK is built by GitHub Actions. This avoids trying to install a full Android SDK toolchain inside the phone's Termux environment.

## 1. Download the APK artifact

1. Open the latest successful Android CI run in the repository's Actions tab.
2. Download the artifact named `aura-debug-apk`.
3. The downloaded file is a ZIP archive. Save it in the phone's Downloads folder.

## 2. Open Termux

Run:

```sh
termux-setup-storage
pkg update -y
pkg install unzip coreutils -y
cd ~/storage/downloads
mkdir -p aura-install
unzip -o aura-debug-apk.zip -d aura-install
sha256sum aura-install/app-debug.apk
termux-open aura-install/app-debug.apk
```

Android's package installer will open. Review the package and confirm installation manually.

## 3. First launch

1. Open AURA from the app drawer.
2. Grant Camera permission.
3. Tap Start Session.
4. Tap Accessibility Settings and enable AURA Device Control manually.
5. Return to AURA. The foreground notification confirms the active camera session.

Use the in-app Stop Session button or the Stop AURA notification action to stop camera access.

## Notes

- No root access is required.
- Termux cannot silently grant Camera or Accessibility permissions; Android requires direct user approval.
- If Android blocks installation, allow this installation source in Android Settings, then retry.
- The APK is a debug build generated by CI. It is suitable for testing, not a Play Store release.
